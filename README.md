# Best Match AI

## Overview
A frontend Angular application designed to help resource managers, salespersons, and talent acquisition teams find the right people with the help of AI. The lifecycle starts with the upload of resumes, and the AI will extract all the information from the CV, such as years of experience, skills, and companies they have worked for.

After storing this information in the database and storing the CV in the file system, the user can search for the best match for a specific mission using any keywords they have. Using these keywords, the AI will generate a list of relevant keywords and compare them to the extracted information from the CVs, creating a score based on the matches.

The user can also ask questions about the CV from the UI to see if it is a good match. The AI will also provide its own estimation of the percentage of matching.

NB: Look at the backend readme.md for more details on the backend.

## Usage of the application

there is only one page the is relevent to the user which is the search page, the user can search for the best match for a specific mission using any keywords they have. Using these keywords, the AI will generate a list of relevant keywords and compare them to the extracted information from the CVs, creating a score based on the matches.

The main page is `Best match Resource` where the upload, search and the interactive chatbot for resume are located.

You can start with uploading a list of resumes (you can select multiple in the same time) and then click on upload, note that the upload progress maybe stuck at some point but please don't worry the upload is still in progress the issue is the OpenAI API can throw a 429 error if the request is too frequent but don't worry since in the backend will do 4 retries every 45 seconds before failing the request. the same goes for the interactive chatbot for resume.

After the upload is done you can search for the best match for a specific mission using any keywords you have. Using these keywords, the AI will generate a list of relevant keywords and compare them to the extracted information from the CVs, creating a score based on the matches.

You can see the Matched keywords in the table with green background and An accuracy percentage for each resume.

For Debuging purposes you can change the request and response of the AI in the backend console (To be removed in production).

You can also check the Tags generated by the AI at very bottom of the page.

## Some Stuff to take as consideration

- The interactive backgroud in the page should be removed in production since it uses a lot of resources specially the CPU/GPU of the user. it can be added to logging page for example but not in the page that the user will use frequently.
